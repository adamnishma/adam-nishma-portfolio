# Adam Nishma Portfolio

A standalone static recreation of the product design portfolio. It uses plain HTML, CSS, JavaScript, local images, and local video assets. No CMS, build step, framework, or server runtime is required.

## Hosting

Upload the contents of this folder to any static web host. Keep the `assets`, `css`, `js`, and `work` folders beside `index.html`.

## Pages

- `index.html` - portfolio homepage
- `work/quan.html` - Quan / TrueTribe case study
- `work/search-in-a-box.html` - Search in a Box case study
- `work/brenntag.html` - Brenntag Source case study
